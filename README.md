# Ejercicio de aplicación a BIM

Esta app se desarrolló con la estructura solicitada, siguiendo las instrucciones del ejercicio.

## Cómo ejecutar
No uso `npm`, uso `bun`. Para iniciar el proyecto de preferencia usa:
```
bunx expo start -c
```
